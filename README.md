# 💻 Meu Portfólio & Currículo Web

Seja bem-vindo ao repositório do meu portfólio pessoal e currículo profissional! Este projeto foi desenvolvido com o objetivo de centralizar minhas experiências, demonstrar minhas habilidades técnicas na prática e documentar minha evolução no universo da tecnologia.

O site foi construído de forma totalmente responsiva, garantindo uma excelente experiência de leitura e navegação tanto em computadores quanto em dispositivos móveis.

## 🛠️ Tecnologias e Conceitos Aplicados

Para a construção deste projeto, apliquei conceitos fundamentais de desenvolvimento web front-end, focando em semântica e organização visual:

- **HTML5:** Estruturação semântica e acessível do conteúdo.
- **CSS3 Avançado:** Uso estratégico de **CSS Grid Layout** e **Flexbox** para a criação de malhas e alinhamentos complexos.
- **Design Responsivo:** Uso de Media Queries para garantir que o layout se adapte perfeitamente a qualquer tamanho de tela.
- **Versionamento com Git:** Controle de versão rigoroso e boas práticas de commits para o deploy no GitHub.
